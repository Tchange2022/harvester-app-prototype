# 特查恩采收机器人 App · 交互原型

智耘采收机器人配套手机端 App 的 5 屏高保真交互原型。

> 在线演示：**https://tchange2022.github.io/harvester-app-prototype/**（手机/电脑浏览器均可直接点开操作）

## 页面结构

| 页面 | 说明 |
|------|------|
| P1 首页 | 设备状态总览、今日任务、快捷入口 |
| P2 新建任务 | 地块选择、成熟度/速度档位、启动前安全自检 |
| P3 实时监控 | 识别画面模拟、异常告警、暂停/急停/语音对讲 |
| P4 数据中心 | 采收日报、周趋势、成本节省估算、报告导出 |
| P5 AI助手 | 故障问答（对话式排查 + 转人工入口） |

## 配套作品

- **PRD 文档**：完整 12 章（用户画像 / 需求优先级 / 信息架构 / 流程图 / 验收标准）
- **Coze 智能体**：P5 AI 助手的实际落地实现（https://www.coze.cn/store/agent/7688350226804932643）
- **Figma**：同版式的静态设计稿

## 技术说明

单文件纯 HTML/CSS/JS 实现，无依赖，可直接 `index.html` 打开运行。
